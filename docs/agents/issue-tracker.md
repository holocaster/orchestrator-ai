# Issue tracker: Local Markdown

Issues and specs for this project live as Markdown files in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- Feature spec: `.scratch/<feature-slug>/spec.md`
- Implementation issue: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Number implementation issues from `01`.
- Record triage state with a `Status:` line near the top of the file.
- Append discussion under a `## Comments` heading.

When a skill says to publish to the issue tracker, create the corresponding file under `.scratch/`.
