# Domain Docs

This is a single-context project.

Before exploring or changing the project:

1. Read the root `CONTEXT.md`.
2. Read relevant decisions under `docs/adr/`.
3. Use the canonical terms from `CONTEXT.md` in specs, issues, tests, and code.
4. Surface conflicts with an ADR instead of silently overriding it.

If a required domain term is missing, reconsider the language or resolve the gap through domain modeling before adding it.
